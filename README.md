# 锐Owl 实测数据（Evidence & Reproductions）

这里放**锐Owl 自己跑出来的实测原始记录**：不是结论转载，是**可复现的过程数据**。

## 口径声明（先读这段）

- **本地与云不混评**：每条记录都标了运行环境（`local` = 本机 Mac / `cloud` = 云 GPU 或云 API），两边的数字不放在一起比。
- **只放自己的数据**：第三方与论文数字一律出处标注，不进本仓（那些在文章里走「来源表」）。
- **跑得不好也放**：按预注册的判据跑完就落盘，不挑好看的那次（对局类按 A-B-B-A 各跑两轮，两轮都留）。
- **有更正就写更正**：判据改过的地方留痕（例：ep15 的 J4 由 v1.0 加强为 v1.1，只作用于已采集数据，方向是更严）。
